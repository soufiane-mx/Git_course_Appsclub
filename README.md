## 📖 About the Course

Welcome to the **Git Course at AppsClub**!

This repository contains the learning materials, presentations, and practical exercises used throughout the course.

The goal is to introduce learners to version control, help them understand Git's essential concepts, and teach them how to manage projects and collaborate with others using tools such as GitHub and GitLab.

Whether you're a beginner or a student working on your first development projects, learning Git is an essential step toward becoming a better developer.

## 📚 Course Sessions

### 🟠 Session 1 — Introduction to Git

Learn the fundamentals of version control and understand how Git tracks changes in a project.

Topics include:
- What is version control?
- Git vs. GitHub vs. GitLab
- Understanding the Git workflow
- Initializing a repository with `git init`
- Checking changes with `git status` and `git diff`
- Staging files with `git add`
- Saving changes with `git commit`
- Exploring commit history with `git log`

### 🔵 Session 2 — Branching & Collaboration

Discover how Git helps developers work on different features and collaborate on projects.

Topics include:
- Understanding branches
- Creating and switching branches
- Comparing and merging branches
- Working with remote repositories
- Cloning repositories
- Pushing and pulling changes
- Connecting local projects to GitHub or GitLab
- Understanding collaborative workflows

## 💻 Getting Started

### 1. Install Git

Download Git from the official website:

🔗 https://git-scm.com/

Verify your installation:

```bash
git --version
```

### 2. Configure Git

Set your name and email for your commits:

```bash
git config --global user.name "Your Name"
git config --global user.email "your@email.com"
```

Check your configuration:

```bash
git config --list
```

### 3. Create Your First Repository

```bash
mkdir my-project
cd my-project
git init
```

### 4. Track and Commit Changes

```bash
git status
git add .
git commit -m "Initial commit"
git log
```
